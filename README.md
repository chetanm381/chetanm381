## Currently building: BidForge

**BidForge** is a real-time auction platform designed around the engineering challenges that matter in production:

- Concurrent bid processing and data consistency
- Real-time updates with SignalR
- PostgreSQL persistence and Redis caching
- RabbitMQ-based asynchronous workflows
- Transactional outbox and idempotent consumers
- JWT authentication and role-based authorization
- Automated testing with xUnit and Testcontainers
- Structured logging, metrics, tracing, and load testing
- Docker-based local development and Azure deployment

The project is being delivered through weekly Scrum sprints with Jira-linked branches, pull requests, CI quality gates, architecture decisions, and release documentation.
